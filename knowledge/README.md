# Knowledge Base SuperMoskitka

Это бизнес-знания Jarvis, а не исходный код TypeScript.

## Статусы правил

- `approved` — рабочие знания, которые loader отдаёт Jarvis
- `draft` — ещё не применяются
- `rejected` — не применяются

История версий правила не удаляется: старые версии остаются в `versions`.

## Обучение

Jarvis **не имеет права** автоматически approve собственные предложения.

Цикл:

1. владелец фиксирует ошибку / коррекцию
2. создаётся `LearningSuggestion` со статусом `pending`
3. владелец делает approve / reject / edit
4. только после approve правило может стать `approved`

## Источник истины

Сейчас источник истины — YAML-файлы в этом каталоге. Изменения бизнес-правил проверяются через Git.

В будущем появится UI владельца, но файлы Knowledge Base останутся каноническим представлением правил.
