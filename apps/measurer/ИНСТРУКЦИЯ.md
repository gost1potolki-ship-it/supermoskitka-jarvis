# Калькулятор Замерщика — Инструкция по использованию

## Запуск приложения

При запуске отображается загрузочный экран с логотипом компании «СУПЕРМОСКИТКА». Через несколько секунд открывается главное меню.

---

## Главное меню

В меню доступны четыре раздела:

- **Активные замеры** — список предстоящих выездов, загружается из облака
- **Калькулятор продукции** — расчёт стоимости изделий и формирование заказа
- **Архив замеров** — история всех сохранённых заказов
- **Настройки** — управление прайс-листами (доступ по паролю)

---

## Активные замеры

Экран показывает список запланированных замеров с информацией:

- Адрес объекта
- Имя клиента и телефон (нажатие — звонок)
- Время замера и комментарии
- Тип оплаты (заказчик / фирма)

**Что можно сделать:**

- Отметить замер как выполненный (чекбокс)
- Открыть адрес на карте (Яндекс Карты, 2ГИС, Google Maps)
- Построить маршрут в Яндекс Навигаторе
- Нажать «Начать замер» — данные клиента автоматически перенесутся в текущий заказ

## Калькулятор продукции

### Выбор типа изделия

Доступны три категории:

**Москитные сетки:**
- Рамочные (стандартные оконные)
- КРЫЛО (сетка в проём)
- Внутривставные VSH
- Дверные (на петлях)
- Рулонные
- Плиссе Сетки (гармошкой)

**Шторы ПЛИССЕ:**
- ПОРТАЛ (классические с рамой)
- ЛАЙТ (облегчённая система)
- УЮТ + (вставная/накладная система)

**Обслуживание окон:**
- Уплотнительная резинка
- Гребёнка
- Детский замок
- Регулировка окон и дверей

### Расчёт изделия

После выбора типа открывается экран расчёта. В зависимости от типа изделия доступны:

- **Размеры** — ширина и высота в миллиметрах (или количество для услуг)
- **Полотно/ткань** — стандарт, антикошка, антипыль, Blackout и др.
- **Цвет профиля** — белый, коричневый, серый, RAL-покраска
- **Профиль** — выбор толщины (25 мм / 32 мм / 42 мм)
- **Уголки** — пластиковые или алюминиевые
- **Ручки** — пластиковые или металлические
- **Крепления** — стандарт, Z-металл, плунжер
- **Открывание** — тип открывания для дверей и плиссе
- **Порог** — стандартный или низкий (для плиссе)

Стоимость пересчитывается в реальном времени при каждом изменении параметров. Если размеры выходят за допустимые пределы — появится предупреждение.

Нажмите **«Добавить в заказ»** для добавления изделия в корзину.

## Корзина

### Данные клиента

В верхней части корзины заполните:

- **Имя клиента**
- **Телефон**
- **Адрес объекта** — можно ввести вручную или нажать кнопку выбора адреса из базы активных замеров (поиск по адресу или имени)

### Позиции в заказе

Каждая позиция отображает полное описание изделия: тип, размеры, материалы, цвет, количество и стоимость.

Для каждой позиции можно:
- Изменить количество (кнопки «+» и «−»), цена пересчитается автоматически
- Отредактировать параметры (нажать на позицию)
- Удалить (кнопка корзины)

### Монтаж

Переключатель «Нужен монтаж». При включении стоимость монтажа рассчитывается автоматически:
- Одно рамочное/крыло изделие — 900 ₽
- Несколько рамочных/крыло — по 500 ₽ за каждое
- Другие типы изделий — индивидуальный расчёт по прайсу

### Доставка

Три варианта:
- **Самовывоз** — бесплатно
- **По городу** — фиксированная стоимость из прайса
- **За город** — базовая стоимость + цена за каждый километр (введите расстояние)

### Комментарий к замеру

Текстовое поле для заметок мастера. Два способа ввода:

1. **Текстом** — вводите с клавиатуры
2. **Голосом** — удерживайте кнопку «Голос», говорите, отпустите. Речь автоматически распознаётся и добавляется в комментарий

Кнопка «Очистить» удаляет весь текст комментария.

### Итого

В нижнем блоке отображается:
- Стоимость позиций
- Стоимость монтажа (если включён)
- Стоимость доставки
- **Итого к оплате** (округлено до десятков рублей)

### Отправка заказа

- **КП заказчику** — коммерческое предложение клиенту через WhatsApp, Telegram или SMS
- **Менеджеру** — отчёт с полными данными (включая комментарии) в Telegram
- **В архив** — сохранение заказа в облако. После сохранения заказ появится в архиве на всех устройствах, а в разделе «Активные замеры» этот замер автоматически получит статус «выполнен» (чекбокс переключится)
- **Отмена** — очистка текущего заказа (с подтверждением)

---

## Архив замеров

Список всех сохранённых заказов, отсортированных по дате (новые сверху).

Для каждого заказа отображается:
- Данные клиента (имя, телефон, адрес)
- Состав заказа с ценами
- Услуги (доставка, монтаж)
- Комментарии
- Дата замера

Действия:
- Развернуть/свернуть детали заказа
- Повторно отправить отчёт (WhatsApp / поделиться)
- Удалить замер из архива (с подтверждением)

## Настройки (Админ-панель)

**Доступ по паролю: `3673108`**

### Личные данные

Имя мастера — используется в коммерческих предложениях и отчётах.

### Управление ценами

Цены разбиты на группы-аккордеоны. Нажмите на группу, чтобы развернуть:

**Рамочные сетки (Классика):**
- Профили (м.п.) — цены по цветам и толщинам
- Коэффициенты и работа — наценки, коэффициент прибыли
- Полотна (м²) — цены типов полотен
- Уголки, крепления, ручки, петли — цены по типам

**Сетки ПЛИССЕ:**
- Коэффициенты, профили, полотна, комплектующие

**Шторы ПЛИССЕ:**
- Коэффициенты, ткани, система ЛАЙТ, система УЮТ

**Обслуживание окон:**
- Тарифы на работы

**Логистика и Монтаж:**
- Доставка (базовая цена, цена за км)
- Монтаж по типам изделий

### Действия

- **Сохранить** — отправляет изменённые цены в облако. Все устройства получат обновление автоматически
- **Сбросить** — возврат к ценам по умолчанию

## Важные особенности

### Работа офлайн

Приложение работает без интернета:
- Текущий заказ (черновик) сохраняется локально при каждом изменении
- Цены кэшируются локально
- При восстановлении связи данные синхронизируются с облаком

### Синхронизация

- Прайс-листы синхронизируются между всеми устройствами в реальном времени
- Изменение цены в админке на одном телефоне — мгновенно видно на остальных
- Архив замеров хранится в облаке и доступен с любого устройства

### Округление цен

Итоговая стоимость каждой позиции и общая сумма заказа округляются до десятков рублей (например: 8179 → 8180 ₽).
