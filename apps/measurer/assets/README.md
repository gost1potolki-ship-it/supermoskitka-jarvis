# Иконка и экран загрузки приложения

## Смена иконки приложения (Android и веб)

1. **Подготовьте изображение иконки**
   - Формат: PNG или JPG
   - Размер: **не менее 1024×1024 px**
   - Имя файла: `icon.png`

2. **Положите файл в эту папку**
   ```
   assets/
   └── icon.png
   ```

3. **Установите генератор ресурсов (один раз)**
   ```bash
   npm install @capacitor/assets --save-dev
   ```

4. **Сгенерируйте иконки для Android и веба**
   ```bash
   npx @capacitor/assets generate --iconBackgroundColor '#ffffff' --iconBackgroundColorDark '#1f2937'
   ```
   Цвета фона можно заменить на свои (в формате `#RRGGBB`).

5. **Синхронизируйте с Android**
   ```bash
   npx cap sync android
   ```

После этого иконка обновится в сборке приложения для смартфона.

## Иконка в браузере (вкладка)

Файл `public/favicon.svg` используется как иконка во вкладке браузера. Чтобы заменить её — подставьте свой SVG или положите в `public/` файл `favicon.ico` (и при необходимости обновите ссылки в `index.html`).
